Arquitetura de Layout JavaFX (Camadas)

Este documento detalha a estrutura hierárquica dos nós (Nodes) JavaFX utilizados na construção da interface do Guess Quest. A aplicação utiliza um design responsivo baseado em contêineres aninhados.

1. Estrutura Global (Root)

A raiz de todas as telas é sempre um StackPane. Este layout foi escolhido por permitir o empilhamento de elementos (camadas) uns sobre os outros, essencial para efeitos de fundo e sobreposições.

StackPane (Root) ├── VBox (CRT Overlay - Efeito Scanline) └── BorderPane (Arcade Container - Onde o jogo acontece) ├── Top (Cabeçalho) ├── Center (Área Principal Dinâmica) └── Bottom (Menu de Rodapé)

2. Tela Principal (Primary.fxml)

Utiliza uma estratégia de Visibilidade Dinâmica. Todas as "subtelas" (Menu, Dificuldade, Opções) existem simultaneamente dentro do StackPane central, mas apenas uma fica visível (setVisible(true)) por vez.

Camadas do Center (StackPane):

  • Camada 1: Menu de Nome (VBox fx:id="screenNameInput")
    Contém o TextField oculto e os Labels estilizados para os slots de letras.
  • Camada 2: Seleção de Dificuldade (VBox fx:id="screenDifficulty")
    Usa ToggleButton dentro de um ToggleGroup para exclusão mútua.
  • Camada 3: Configurações (VBox fx:id="screenSettings")
    Usa HBox para alinhar Label (esquerda) e Slider (direita) na mesma linha.
  • Camada 4: Créditos (VBox fx:id="screenCredits")
    Fundo semitransparente para destacar sobre o jogo.

3. Tela de Jogo (Secondary.fxml)

Estrutura focada na organização de informações e feedback visual.

  • Top (HBox): Alinha Vidas (Esq), Fase (Centro) e Pontos (Dir) usando regiões espaçadoras (Region HBox.hgrow="ALWAYS").
  • Center (VBox):
    • StackPane da Imagem: Contém a ImageView do jogo e uma camada de "Loading" por cima.
    • GridPane de Respostas: Organiza os 4 botões em uma matriz 2x2. Perfeito para manter alinhamento.
    • HBox de Dicas: Botões de poderes alinhados horizontalmente.

4. Tela de Ranking (Leaderboard.fxml)

Simples e direto, focado na lista vertical.

  • Center (VBox fx:id="scoreBox"): Um contêiner vertical vazio que é preenchido dinamicamente pelo Controller. Cada linha do ranking é um novo HBox criado via código Java.
Nota Técnica: O uso extensivo de VBox (Vertical) e HBox (Horizontal) simplifica o layout responsivo, enquanto o StackPane permite a criação de interfaces ricas com sobreposições sem a complexidade de gerenciar janelas múltiplas.
